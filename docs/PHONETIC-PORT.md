# Bangla Phonetic — Windows / Linux port notes

> For the **Windows Claude**. macOS ships **Bangla Phonetic** in `v1.7.0` as a third
> `.keylayout`: type Bangla the way it sounds (`ami` → আমি, `bhalO` → ভালো, `korrmo` → কর্ম),
> with Bangla appearing **as you type**. Please bring it to Windows (tray) and Linux (IBus).

## Why this should be cheap for you
Bangla Phonetic is **not a new engine** — it is an ordinary dead-key `.keylayout`, exactly
like Bangla Unicode/Classic, just generated by a compiler instead of drawn by hand. Your
`windows/engine/gen_tables.py` + `KLEngine` already turn a Mac `.keylayout` into FSM tables.

1. Run your table generator on **`macos/src/keylayouts/Bangla Phonetic.keylayout`** →
   a third table set (e.g. `phonetic_table.h`).
2. **Windows tray:** add a **Bangla Phonetic** mode next to Unicode/Classic (+ a hotkey if you
   like). **Linux IBus:** add a third engine **Bangla Phonetic**.
3. Verify with the corpus below.

## Details that matter
- **Source of truth is the generator**, `macos/src/phonetic/gen_phonetic.py` (our own MIT rules).
  Never hand-edit the `.keylayout`; change the rules and regenerate (`python3 gen_phonetic.py`).
- **Live preview = the dead state's terminator.** While a word is in progress, the text to show is
  *committed output + terminator(current state)*. Linux: put the terminator in the **preedit**.
  Windows tray: the same back-spacing preview you already do for Unicode works.
- **Case matters for some letters**: `t/T d/D n/N r/R s/S o/O i/I u/U j/J y/Y z/Z G`. Shift+other
  letters = same as lowercase. **Caps Lock alone = plain lowercase** (keyMap 3 is the plain map), so an
  accidental Caps Lock doesn't garble words. Your Shift/Caps handling must follow the keyMap select,
  not "uppercase the character".
- Non-letter action keys: `` ` `` (accent), `,` (`,,` = hasanta), `.` (`.` = ।, `` .` `` = .),
  `:` (`:` = ঃ, `` :` `` = :). Digits → ০-৯, `$` → ৳, `^` → ঁ (direct outputs).
- Output uses precomposed **য় U+09DF / ড় U+09DC / ঢ় U+09DD**, same as Bangla Unicode — compare NFC.
- 119 states, maxout 7 (outputs up to 7 UTF-16 units per key — size your buffers for it).

## Verify
- `macos/src/phonetic/tests.tsv` — typed text ⇥ expected (123 cases). Type each line + a trailing
  Space and compare NFC. All pass on the real macOS engine.
- `macos/src/phonetic/gen_phonetic.py` exposes `type_ref(text)`, the reference model —
  `difftest.py` compares an engine against it on random input (macOS: 4,198 cases, 0 mismatches).

## Known limits (same on every OS)
No dictionary/autocorrect is possible in a static layout. Common words are built-in exceptions
(`amra` আমরা, `tOmra` তোমরা, `ekTa` একটা, `ekTu` একটু, `apni` আপনি); elsewhere users type `` ` ``
between consonants (``jan`te`` → জানতে).
